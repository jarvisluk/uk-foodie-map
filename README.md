# 🇬🇧 英留美食交互式地图 (UK Foodie Interactive Map)

基于真实留英探店记录（2024.9 - 2025.10）打造的交互式全英美食地图系统。

## ✨ 核心特性

- 📍 **137 家精选餐厅 & 全量 GPS 精准定位**：覆盖伦敦各大核心区域（Soho、Battersea、Kensington、White City、London Bridge、Covent Garden 等）以及爱丁堡、曼彻斯特、剑桥、牛津、伯明翰、格拉斯哥、康沃尔等各大城市。
- 📸 **250+ 原生探店实拍照片**：每家餐厅均收录作者实拍美食图、店面图与环境图，支持缩略图轮播与全屏 Lightbox 大图画廊浏览。
- 🌟 **精准分级评价体系**：
  - 🌟 **神店必吃 / 强烈推荐** (金黄星标)
  - 👍 **口碑好店 / 值得一试** (翡翠绿标)
  - ⚪ **普通 / 生命维持 / 可尝** (天蓝标)
  - 👎 **避坑排雷 / 不建议尝试** (绯红标)
  - ⚠️ **已关门 / 闭店提醒** (石板灰标)
- 🔍 **多维度实时搜索 & 联动筛选**：
  - **实时全文检索**：支持搜索餐厅名、菜系、招牌菜品（如“螺蛳粉”、“烤肉”、“生腌”、“海鲜饭”）、英国邮编（如“W1D”、“SW11”）及探店笔记。
  - **城市 & 伦敦片区细分**：支持一键切换城市与伦敦各大热门街区。
  - **菜系分类**：中餐（川菜/粤菜/火锅/烧烤/面食米粉）、亚洲菜（日料/韩料/泰餐/南洋菜）、西餐、甜品饮品、酒吧夜生活。
- 🗺️ **地图平滑导航与聚合聚类**：采用 Leaflet + CartoDB 高清瓦片，支持缩放聚类、气泡预览、卡片点击平滑飞行联动（FlyTo）。
- 🎲 **“今天吃什么？”随机美食轮盘**：智能抽取高分推荐餐厅并一键在地图上定位展示。
- 🧭 **一键导航与地址复制**：详情页集成一键复制精准地址，支持直达 Google Maps 和 Apple Maps 路线规划。
- 🌓 **浅色 / 深色模式**：自动与系统适配或手动一键切换。

## 🚀 启动与使用方式

### 方式 1：本地 Web 服务（推荐）
在项目根目录运行：
```bash
python3 -m http.server 8000
```
然后在浏览器中打开：
[http://localhost:8000](http://localhost:8000)

### 方式 2：直接双击打开
在访达（Finder）中直接双击 `index.html`，无需安装任何运行环境，即可离线加载全部数据与实拍图片！

## 📂 目录结构

```text
sharp-pythagoras/
├── index.html               # 交互式地图主页面
├── app.js                   # 地图交互、筛选、画廊、随机轮盘核心逻辑
├── app.css                  # Modern UI 样式库（响应式、深浅色模式）
├── data/
│   ├── 🇬🇧英留美食.md        # 原始 Markdown 探店笔记
│   ├── restaurants.json     # 解析后的结构化 JSON 数据库（含经纬度）
│   ├── restaurants.js       # 离线环境直读的 JS 格式数据源
│   └── Attachments/         # 250 张探店实拍照片原图
├── assets/vendor/           # 本地化 Leaflet 与 MarkerCluster 资源库
└── scripts/
    └── build_data.py        # Markdown 解析与英国邮编批量地理编码脚本
```
